# Deploy to GitHub + Render (live web app)

## 1. Push to GitHub

The project is already committed locally on branch `main`.

### Create the repository (one-time)

1. Open [github.com/new](https://github.com/new)
2. Repository name: `Telus_Excel_Automation`
3. Visibility: **Private** (recommended — internal ops tooling)
4. **Do not** add README, .gitignore, or license (already in this project)
5. Click **Create repository**

### Push from your machine

Replace `YOUR_GITHUB_USERNAME` with your GitHub username:

```powershell
cd "c:\Users\prasun.tripathi\Desktop\MY\Telus_Excel_Automation"
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/Telus_Excel_Automation.git
git push -u origin main
```

Sign in when Git prompts for credentials (browser or Personal Access Token).

---

## 2. Deploy live on Render (free tier)

1. Go to [dashboard.render.com](https://dashboard.render.com) and sign in
2. Click **New +** → **Blueprint**
3. Connect your GitHub account and select the `Telus_Excel_Automation` repo
4. Render reads `render.yaml` automatically — click **Apply**
5. Wait for the build (~2–3 min). Your live URL will be:

   `https://telus-excel-automation.onrender.com`

   (or similar — shown on the Render dashboard)

### Production notes

- `SECRET_KEY` is auto-generated by Render
- PPT generation timeout is set to **120 seconds** (large Excel files)
- Free tier sleeps after inactivity; first visit may take ~30s to wake
- Excel files are **not** stored — upload → generate → download only

---

## 3. Verify locally before pushing

```powershell
pip install -r requirements.txt
$env:FLASK_DEBUG="false"
gunicorn --bind 127.0.0.1:5000 --timeout 120 web_app:app
```

Open http://127.0.0.1:5000 and test an upload.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `Repository not found` on push | Create the empty GitHub repo first (step 1) |
| Build fails on Render | Check Render logs; ensure `DSD_Mukkamala_February 2026_orig.pptx` is in the repo |
| Generation timeout | Upgrade Render plan or reduce Excel size |
| 502 on first request (free tier) | Wait for cold start, then retry |
